# FahrerTagebuch – Mini-Brand-Guideline

## 1. Marke

**Name:** FahrerTagebuch  
**Claim:** Touren. Zeiten. Übersicht.

Die visuelle Basis ist das freigegebene **Konzept C**: eine reduzierte Straßen-/F-Form mit integrierter Fahrerkarte.

## 2. Farbpalette – verbindlich

| Rolle | Farbe | Hex |
|---|---|---|
| Primär | Navy | `#0F2D4A` |
| Akzent | Petrol | `#008B8B` |
| Neutral | Hellgrau | `#E5E7EB` |
| Hintergrund | Weiß | `#FFFFFF` |

Hinweis: Falls einzelne ältere Konzeptbilder leicht abweichende Hexwerte zeigen, gelten **ausschließlich die Werte dieser Tabelle**.

## 3. Typografie

Primärschrift: **Inter**

Empfohlene Schnitte:

- Bold: große Überschriften
- SemiBold: Abschnittstitel / Kennzahlen
- Medium: Buttons / Labels
- Regular: Fließtext / Tabellen

Keine dekorativen oder handschriftlichen Schriften in der Produktoberfläche.

## 4. Logo

Das Hauptlogo kombiniert:

- stilisierte Route / Straßenform,
- Fahrerkarte als kleines integriertes Element,
- Wortmarke `FahrerTagebuch`,
- optional den Claim `Touren. Zeiten. Übersicht.`

### Nicht erlaubt

- Strecken oder Stauchen
- freie Farbänderungen
- nachträgliche 3D-/Glanz-/Schatteneffekte
- willkürliche Neuordnung der Logo-Bestandteile
- zu dünne Linien, die bei kleiner Darstellung verschwinden

## 5. App-Icon

Für das App-Icon nur das kompakte Symbol verwenden, nicht die komplette Wortmarke.

Android-Ziel:

- Adaptive Icon
- Foreground und Background getrennt
- zentrale Symbolbestandteile innerhalb der Safe-Zone
- klare Lesbarkeit auch bei kleiner Größe

## 6. Logo-Varianten

Mindestens vorsehen:

1. Standard: Navy + Petrol auf Weiß
2. Dunkel: helle Logoform auf Navy
3. Monochrom dunkel
4. Monochrom hell
5. Nur Symbol
6. App-Icon

## 7. Formensprache

Gewünscht:

- klar
- ruhig
- professionell
- reduziert
- viel Weißraum
- dezente Rundungen
- klare Linien
- geringe Schatten

Vermeiden:

- starke Verläufe als dominantes UI-Mittel
- 3D-Effekte
- viele konkurrierende Farben
- verspielte Icons

## 8. Kreis- und Iconregel

Alle kreisförmigen Elemente müssen technisch mit einem festen **1:1-Seitenverhältnis** dargestellt werden.

Das gilt insbesondere für:

- Kreisdiagramme
- Icon-Hintergründe
- Statuskreise
- runde Kennzahlenflächen
- kreisförmige Logoelemente

Icons sollen aus einem konsistenten Vektor-Iconset oder aus sauber erzeugten Vektorassets stammen. Keine grafischen Artefakte oder deformierten Symbole.

## 9. Schutzraum

Um vollständige Logos ausreichend Weißraum lassen. Als einfache Mindestregel kann ungefähr die Höhe der im Logo integrierten Fahrerkarte als freier Rand verwendet werden.

## 10. PDF-Bezug

PDFs verwenden dieselbe Markenwelt, sind aber dokumentartiger:

- weniger Schatten
- weniger appartige Karten
- klare Tabellen
- Navy als Tabellenkopf
- Petrol als sparsamer Akzent
- Weiß/Hellgrau als Grundflächen
