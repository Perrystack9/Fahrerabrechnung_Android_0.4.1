# PR #39 – Kontrolldaten der eigenen Fahrerkarte

Ausgangsbasis: bestandene PR-37-Test-App, Schema 8, Version 40104. Update: Schema 9, Version 40105, gleiche Paketkennung und Testsignatur. Bei vorhandener **FahrerTagebuch Test** ausschließlich `02-FahrerTagebuch-Test-Update.apk` installieren. Nicht deinstallieren oder Daten löschen. Die Ausgangs-APK ist nur für eine neue, getrennte Testinstallation vorgesehen.

1. **Update und Altdaten:** Ohne Leser das Update installieren. Profil, alte Imports, Kartentage und Fahrzeugnutzungen bleiben verfügbar. Bei einem älteren Import unter „Gespeicherte Daten ansehen → Fahrerkarten-Details → Kontrollen“ steht, dass für diese Übernahme keine gespeicherten Kontrolldaten verfügbar sind. Alte Imports bekommen keine neue Kontrolle zugeschrieben.
2. **Eigene Karte automatisch einlesen:** Leser anschließen, eigene Karte einlegen, gegebenenfalls Android-USB-Zugriff bestätigen. Keine neue Erstbestätigung und kein Speichern-Knopf. Kartentage/Fahrzeugnutzungen bleiben nutzbar. Bei erfolgreicher zusätzlicher Lesung erscheint „Kontrolldaten übernommen“. Unter „Gespeicherte Daten ansehen → Fahrerkarten-Details → Kontrollen“ entweder letzte aufgezeichnete Kontrolle mit Datum/Art und verfügbaren Angaben oder ausdrücklich „In dieser Kartendatei ist keine Kontrolle aufgezeichnet.“ Beides kann korrekt sein. Eine vorhandene Kontrollkartennummer zunächst maskiert; „Kartennummer anzeigen/verbergen“ prüfen, falls vorhanden.
3. **Wiederholung und exakter Stand:** Karte erneut herausnehmen/einlegen. Keine Leseschleife, keine zusätzlichen identischen Quelldaten. Im Importverlauf ältere und neue Übernahme einzeln öffnen: Der alte Import behält seinen damaligen Stand, der neue zeigt seine eigenen Kontrolldaten. Falls die Karte inzwischen eine neue Kontrolle enthält, darf diese ausschließlich in neuen Übernahmen erscheinen; eine neue Kontrolle nicht eigens für den Test erzeugen.
4. **Neustart ohne Leser:** Leser entfernen, App vollständig beenden und wieder öffnen. Profil, ältere Daten und neue Kontrolldaten bleiben verfügbar.

Wenn die zusätzliche Datei auf der konkreten Karte nicht gelesen werden kann, muss eine verständliche Teilfehlermeldung erscheinen; die erfolgreich gelesenen Kartentage/Fahrzeugnutzungen bleiben verfügbar. Bitte in diesem Fall nur die Meldung und Kartengeneration nennen. Keine Rohkartendaten oder unmaskierten Nummern versenden.

Automatische Tests decken Gen1/Gen2/Gen2V2, die 46-Byte-Struktur, fehlende/abgeschnittene/ungültige Dateien, leere Kontrollbelege, Abbruch, Fremd-/Ersatzkarten, Deduplizierung, Transaktions-Rollback, exakte Wiederöffnung und Migration 8→9 ab. Der manuelle Test bestätigt nur die vorhandene Geräte-/Leser-/Kartenkombination. Vollständige Kartenabdeckung und fachliche Auswertung sind weiterhin offen.
